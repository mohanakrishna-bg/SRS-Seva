# Aaradhana Invitation Content Archive

This folder contains all images, text, and structured data extracted from the **Sri Sri Sri Guru Raghavendra Swamiji's 355th Aradhana Mahotsava** Invitation Card PDF.

## 📁 Folder Structure

```
Aaradhana Invitation/
├── images/

│   ├── page_3_full.png            # Page 3 full page render (300 DPI, 1654x2599)
│   ├── rayaru_portrait.png        # High-res Sri Rayaru color portrait (785x1043)
│   ├── upi_qr_code.png            # UPI QR code for donation payments (264x259)

├── Aaradhana_Invitation_Text_English.txt  # English transliteration & translations
├── Aaradhana_Invitation_Complete.md       # Formatted Markdown with tables
├── seva_details.json                      # All 13 Sevas with Kannada & English names & rates
├── committee_members.json                 # Executive committee & trustees with phone numbers
```
